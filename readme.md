## Campus Compass ##

Final project for UF COP3530, Fall '26, Kapoor

# Project Goal
- To develop a C++ program to manage on-campus roads and sidewalks connecting student residences and classrooms

# Project Features
- CSV File parsing
- Addition and removal of students
- Managing students' classes
- Opening and closing roads
- Find the shortest route from residences or study zones to classes on the UF Campus, accounting for closures
- Main function to process commands and call appropriate methods
- Catch2 unit tests
